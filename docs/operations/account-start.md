# 普通账号启动指南

状态：准备清单；未注册、未发布。核查日期：2026-10-21。

尚未安装或注册时，先看 [从零开始：设备、安装、网络、注册与语言](zero-to-account.md)。

本阶段考虑个人账号（Personal Account）。官方说明它适合一般用户及内容创作者，并提供创作者工具和分析能力；不需要为了开始创作先切换企业账号。[账号类型说明](https://support.tiktok.com/en/using-tiktok/growing-your-audience/switching-to-a-creator-or-business-account)

## 启动顺序

1. 先核实现实条件：当前所在地能否合法、稳定使用 TikTok，能否完成真实信息注册和正常发布。核对实际账号地区，不能用目标受众地区代替真实注册信息。
2. 使用自己掌握的登录与恢复方式；启用平台提供的账户保护。密码、恢复码与验证码不写入仓库。
3. 选择一个细分受众，写清“这个账号持续解决什么问题”。当前候选方向是运动服饰、日常舒适穿搭或商品细节知识，尚未定案。
4. 准备头像、简介和内容风格。若使用虚拟角色，明确其虚拟属性，不编造所在地、身份或真实使用经历。
5. 制作少量原创内容并检查葡语、素材权利和事实，再由用户确认发布。
6. 记录观察窗口与数据，按周复盘，修改下一批内容。

## 内容方式

先比较真实素材配巴西葡语解说与图文解释。虚拟人物可以作为讲解形式之一，不默认全 AI 试穿展示或全自动发布。

普通账号内容适用社区规则。显著使用 AI、合成语音或真实感虚拟人物时，按当时的披露要求操作；将来出现商业推广时还要核对商业披露。不能因为未挂商品链接，就假定所有产品推广都不是商业内容。

## “养号”的工作定义

积累清晰的主题、真实内容、目标受众反馈和稳定的制作习惯。不把刷粉、互赞、复制视频、批量注册或所谓固定养号天数纳入计划。

推荐系统会参考观看、互动、内容和用户信息，语言本身不保证流量来自巴西。需要通过实际后台信息和相关互动验证受众匹配。[官方推荐机制](https://support.tiktok.com/en/using-tiktok/exploring-videos/how-tiktok-recommends-content)

## 未来资格与当前任务分开

当前不申请带货，但保留账号地区、内容主题、素材权利和身份真实性的记录，避免形成未来无法解释的资料。等商业化条件成熟时再核查平台准入，不能把当前普通账号可发布当作未来必然可挂商品和提现的证明。
