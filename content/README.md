# 内容工作区

存放选题、脚本、字幕和发布配文。当前尚无已发布内容。

建议每条内容一个目录，例如 `content/2026-11-01-001-size-guide/`，包含 brief.md、script-pt-BR.md 和 review.md；只有实际开始制作后再创建。

使用 [内容简报模板](templates/post-brief.md)。机器生成的葡语必须标记“待审稿”，没有本地审核时如实记录，不假装完成。

文件状态使用：想法 → 草稿 → 已审核 → 待发布 → 已发布 → 已复盘。发布链接及日期只有真实发布后才能填写。

授权素材原片进入 assets/raw/（默认不上传），可公开素材的来源与权利写入对应简报。
